Privacy Policy — Terminal Theme for Perplexity

Effective date: 2026-05-26

What this extension does

Terminal Theme for Perplexity applies a CSS visual theme to www.perplexity.ai. It does nothing else.

Data collection

None. The extension does not collect, transmit, store remotely, sell, or share any personal data, browsing data, prompts, or responses.

Local storage

The extension stores a single boolean value (whether the theme is active) in your browser via chrome.storage.local. This data never leaves your device.

Permissions

  • storage — to remember whether the theme is enabled.
  • host permission for www.perplexity.ai — to inject the CSS theme on that domain only.

Third parties

None. No analytics, no telemetry, no third-party scripts, no network requests.
